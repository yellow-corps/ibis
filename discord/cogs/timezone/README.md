# TimeZone

A cog for setting the timezone, used by other cogs.

## Usage

- Must be a bot owner to use commands.
- Bot wide.

### Load

```discord
[@] load timezone
```

### Setup Timezone

Get or set the configured timezone.

_See TZ identifiers on [List of tz database time zones](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones) for valid timezone names to use._

```discord
// get timezone
[@] timezone get

// set timezone
[@] timezone set America/New_York

// clear timezone
[@] timezone clear
```
